# 界面：「大肥鱼化」（v0.3.0）

原版界面是纯 `tk` 默认控件：方块按钮、灰底、没有层级。这一版把界面重做成一套自绘外观，
品牌色沿用 DeepSeek 的蓝 `#4D6BFE`，图标换成官方那条鲸鱼。**功能一行没减**，改动只在
`ui_kit.py`（新增）与 `dsh_lanes_gui.py`。

---

## 1. 自绘控件 `ui_kit.py`

tkinter 原生控件没有圆角、没有 hover、按钮只有「按下」才变色。要做出现代桌面应用的观感，
只能在 `Canvas` 上自己画。`ui_kit.py` 是**纯标准库**（只用 `tkinter` + `math`），提供：

| 控件 | 用途 |
| --- | --- |
| `RoundedButton` | 圆角按钮，4 种变体（主 / 次 / 幽灵 / 危险）× 3 种尺寸 × 3 态（常态 / 悬停 / 按下），可选前置图标 |
| `RoundedCard` | 圆角卡片 / 圆角面板；`fill=True` 时撑满父容器，用来装日志这类可滚动区 |
| `Pill` | 状态胶囊（圆点 + 文字，全圆角）：运行中 / 已停止 / 异常 |
| `Chip` | 标签芯片：版本号、`★ 主要版本`、dist-tag |
| `MiniScrollbar` | 极简滚动条（只有一根圆角滑块），接口同 `tk.Scrollbar` |
| `divider()` | 1px 分隔线工厂 |

刻意遵守的一条约束：**API 向 `tk.Button` 靠拢** —— `.pack()` / `.grid()` / `configure(text=…)` /
`cget("text")` / `.invoke()` 都能用。这样把老的 `tk.Button` 换掉时，调用点一行都不用改。

单独看控件：`py ui_kit_demo.py`；无窗口自检：`py ui_kit_demo.py --smoke`。

## 2. 布局改了什么

| 位置 | 原来 | 现在 |
| --- | --- | --- |
| 顶栏 | 三行文字 | 压成两行；dist-tag 从一串字改成芯片；窄窗口自动少显示几个芯片 |
| 卡片 | `tk.Frame` 平铺 | `RoundedCard` + 悬停高亮 + **左侧状态色条** + 标题加大 |
| 版本 / 状态 | 纯文字 | `Chip` 版本号、`Pill` 状态胶囊 |
| 日志面板 | `Text` 直接往里灌 | 时间戳列 + 级别字形 + 小节留白 + 空状态 + 「自动滚动已暂停」提示 + 极简滚动条；**批量插入**、上限 4000 行 |
| 窗口骨架 | 到处同色 | 白底工具栏 / 状态条 + 内容区浅灰，做出层级 |
| 底部 | 一串蓝色文字链接 | 幽灵按钮；底部说明不再被挤成竖条 |

设计令牌（色板、字号、圆角、间距）都集中在 `ui_kit.py` 顶部的 `TOKENS`，改主题只动那一处。

## 3. 图标：官方鲸鱼

`assets/app.ico`（16 / 24 / 32 / 48 / 64 / 128 / 256 七档，透明底）与 `assets/app.png`（512×512）
由 dsh 前端自带的 `@deepseek-ai/dsh-web-frontend/dist/favicon.svg` 光栅化而来：

- 形状就是官方那条鲸鱼（单条 SVG path），品牌蓝 `#4D6BFE`，眼睛和鳍缝是真洞；
- 光栅化脚本自带「SVG path → 非零环绕扫描线填充」，4 倍超采样 —— 本机没有 cairosvg / resvg，
  无头浏览器在这个环境里也起不来，所以没引第三方依赖；
- 窗口标题栏（`root.iconbitmap`）与 exe 的 PE 图标用的是同一份 `app.ico`。

想换图标：替换 `assets/app.ico` 之后重新打包即可；只改某个快捷方式的图标，在
「属性 → 快捷方式 → 更改图标」里选这个 ico。

## 4. 46 KB 的轻量壳（`tools/dsh_stub.cs`）

别人的启动器都是很小的 exe，因为它不装程序，只是去**找**已安装在系统里的主程序再拉起来。
这里做的是同一件事，主程序是「本机的 Python + `dsh_lanes_gui.py`」：

```bat
tools\build_stub.bat
```

| | |
| --- | --- |
| 体积 | **46 KB**（对比 PyInstaller 文件夹版：exe 2.3 MB + `_internal\` 22.3 MB） |
| 里面 | 一个 ~130 行的 C# 壳，`/target:winexe`（GUI 子系统 → 不弹黑窗口） |
| 本机要装 Python 吗 | 要（3.8+，带 tkinter） |
| 改完 `.py` 要重新打包吗 | **不用**，改完直接生效 |
| 找 Python 的顺序 | `DSH_LANES_PY` 环境变量 → PATH 里的 `pyw.exe -3` → 注册表 `PythonCore\3.x\InstallPath` → PATH 里的 `pythonw.exe` |

找不到 Python / 解释器起不来时会弹对话框说明，不会静默退出。旧的 PyInstaller 打包流程
（`build_exe.bat`，产物在 `dist\`）仍然可用，见 README 第 10 节；exe 不进仓库。

## 5. 顺手修掉的四个坑（都在 `dsh_lanes.py` 里）

1. **不弹黑窗口**：所有 `subprocess` 调用统一加 `creationflags=CREATE_NO_WINDOW`
   （`_no_window()` / `_new_group_flags()`）。GUI 壳是 `pythonw`，但从它里面起的 `npm` / `node`
   默认仍会闪一下控制台。
2. **受限令牌**：`token_state()` 读进程的完整性级别与 `IsTokenRestricted`。被关在受限沙箱里时
   写文件会报 `PermissionError [Errno 13]`、`taskkill` 也杀不掉别人的进程 —— 这**不是**目标目录的
   权限问题（`icacls` 看着完全正常）。检测到受限时界面横幅直接说明，别让人去查 D 盘权限。
3. **日志文件被占用**：`open_log_append()` 先重试，再换一个带时间戳的文件名，再换目录
   （程序目录 → `%LOCALAPPDATA%` → `%TEMP%`），全都不行就不记日志但**照常启动 lane**。
4. **端口被占却读不到 PID**：`probe_dsh_like()` 确认应答方像不像 dsh，像就直接接管，
   不再白起一个 `node` 去撞 `EADDRINUSE`。

## 6. 怎么验

```bat
py dsh_lanes_gui.py --selfcheck     :: 窗口能构建、界面入口齐全，不开窗口
py ui_kit_demo.py --smoke           :: 控件自检
py dsh_lanes_gui.py                 :: 真机点一遍
```

> ⚠️ 别随手跑 `selftest.py`：它对每条 lane 做 `open → 握手 → stop`，会把正在用的那套一起停掉。
